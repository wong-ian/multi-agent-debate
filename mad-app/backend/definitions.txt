1.1 Disobey Task Specification:
Occurs when an agent fails to adhere to the core rules of the debate (e.g., an agent assigned to argue "FOR" suddenly argues "AGAINST", or a "Judge" agent starts debating instead of judging).

1.2 Disobey Role Specification:
Failure to act as the assigned persona. For example, a "Moderator" taking a side, or a debater breaking character (e.g., "As an AI, I cannot have an opinion").

1.3 Step Repetition (Stagnation):
Occurs when an agent repeats the EXACT same argument, phrasing, or reasoning from a previous round without adding new evidence, nuance, or rebuttal.
* CRITICAL EXCEPTION: In a debate, maintaining a consistent core stance is REQUIRED. Do not flag this as failure unless the agent is "looping" verbatim or fails to advance the argument with new supporting details.

1.4 Loss of Conversation History:
Occurs when an agent hallucinates or forgets facts established earlier in the *same* debate session (e.g., Debater A accepts a statistic in Round 2 but claims it was never provided in Round 3).

1.5 Unaware of Termination Conditions:
Occurs when an agent tries to continue the debate after the Moderator/Judge has declared it over, or conversely, tries to stop the debate before the round limit is reached.

2.1 Conversation Reset:
The agent behaves as if the debate just started, ignoring all previous rounds of context (e.g., introducing themselves again in Round 3).

2.2 Fail to Ask for Clarification:
The agent makes up an answer to a vague counter-point instead of asking for specifics (only applicable if the opponent's point was genuinely unintelligible).

2.3 Task Derailment (Off-Topic):
The agent abandons the debate topic entirely to discuss unrelated matters (e.g., switching from "AI Safety" to "Pizza Toppings").
* CRITICAL EXCEPTION: Discussing related sub-topics (ethics, history, philosophy, economics) is VALID and should NOT be flagged as derailment.

2.4 Information Withholding:
(Rare in debate) Occurs if an agent claims to have evidence/data to support a crucial claim but refuses to state it when directly challenged.

2.5 Ignored Other Agent's Input:
Occurs when an agent behaves as if the opponent's previous message never happened.
* CRITICAL EXCEPTION: Disagreement is NOT ignoring. If Agent A acknowledges Agent B's point but argues against it, that is a SUCCESS. Failure only occurs if Agent A completely skips a direct question or rebuttal.
* TIMELINE EXCEPTION: An agent cannot "ignore" input that hasn't happened yet (e.g., the first speaker in a round cannot ignore the second speaker).

2.6 Action-Reasoning Mismatch:
The agent's internal reasoning (if visible) contradicts their spoken argument (e.g., "I know this statistic is false, but I will use it anyway").

3.1 Premature Termination:
The agent attempts to end the debate ("I have nothing more to say") before the assigned round limit is reached.
